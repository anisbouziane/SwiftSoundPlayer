# SwiftSoundPlayer

A lightweight and pure Swift audio player for iOS — simple to use, easy to integrate, and fully open source.

## 🚀 Features

- Play local or remote audio files
- Lightweight and dependency-free
- Supports background playback
- Simple and Swifty API

## 📦 Installation

Use [Swift Package Manager](https://swift.org/package-manager/) to install:

1. Open your Xcode project
2. Go to **File > Add Packages...**
3. Enter the repo URL:

```text
https://github.com/anisbouziane/SwiftSoundPlayer.git
